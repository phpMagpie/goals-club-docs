# 🎨 1. Core Visual Design System

## Badge Shape (locked)

* **Circle**
* Thick outer border (important for patches)
* Inner padding so animal never touches edge

---

## Style Direction (non-negotiable rules)

👉 Every badge must follow:

* Flat illustration (no gradients)
* 2–4 colours max
* Bold outlines (for stitching/printing)
* Minimal detail (avoid noise)
* Friendly proportions (slightly oversized heads, soft shapes)

---

## Visual Tone

Think:

* Calm, outdoorsy, wholesome
* Slightly playful, not childish
* “National Trust meets Duolingo”
