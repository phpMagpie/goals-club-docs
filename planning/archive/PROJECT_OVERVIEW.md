# The Goals Club - Project Overview

## Vision
A social platform where people can set, share, and encourage others to complete meaningful personal goals. Building a supportive community focused on physical and mental health improvement through the creation of local "Goal Clubs".

---

## Core User Types

### 1. Goal Setters (Regular Users)
- Register and create a minimal profile
- Create personal goals (single goals - milestone/event based or recurring)
- Join other people's shared goals ("I'd like to do that too!")
- Log activity/progress with photos
- Share progress and receive encouragement
- Earn virtual and physical badges/patches

### 2. Event Organisers
- Register (requires admin approval)
- Create and manage events (requires initial approval, trusted organisers can self-publish later)
- Allow users to join events
- Revenue opportunity for platform sustainability

### 3. Local Goal Club Leaders (future role)
- Facilitate local goal-achievement communities
- Organise meetups and group activities
- Built organically from geographic proximity + shared goal interests

### 4. Spectators/Supporters (future role)
- Non-participating users who follow and encourage others
- Family members, friends cheering on goal-setters
- Potential conversion pathway to becoming goal participants

## Key Decisions Made

### Goal Mechanics
| Decision | Detail |
|----------|--------|
| **Goal Type** | Single goals only - milestone/event based OR recurring (e.g., weekly distance) |
| **Goal Progression** | Users complete goals then move to similar/larger goals naturally |
| **Privacy Levels** | Public, Private, or Shared with Select Members |
| **Joining Goals** | Creates a community goal - "I'd like to do that too!" Others can opt to join shared goals |
| **Goal Sharing** | Opt-in - encourage sharing but allow private tracking for less confident users |

### Social & Community
| Decision | Detail |
|----------|--------|
| **Privacy Default** | Private-first - all content private by default |
| **Sharing Controls** | User-level default + per-goal override (private/friends/public) |
| **Following Default** | Disabled by default - users opt-in to being followable |
| **Encouragement System** | Pre-determined reaction selection (users choose which to use) |
| **Custom Reactions** | Users can suggest new reactions (moderated before adoption) |
| **Local Goal Clubs** | Organic formation based on geographic proximity + shared goal interests |
| **Comments/Messaging** | Minimal until community trust established |

### Verification & Trust
| Decision | Detail |
|----------|--------|
| **MVP Verification** | Trust-based system initially |
| **Future Verification** | Strava integration first (post-launch), then Apple, Fitbit, Garmin |
| **Event Organiser Approval** | Admin approval required for organisers and their events initially |
| **Trusted Organisers** | Can self-publish once trust established over time |

### Badges & Rewards
| Decision | Detail |
|----------|--------|
| **Badge Design** | Platform designers primarily, community suggestions welcomed |
| **Partner Badges** | Future marketplace for custom badges/patches (commission-based) |
| **Virtual Badges** | Auto-assigned on goal completion |
| **Physical Merchandise** | Users order from completed goals section |

### Profile Requirements
| Field | Required | Displayed |
|-------|----------|-----------|
| Username | ✅ Yes | ✅ Public |
| Display Name | ❌ Optional | ✅ If set |
| Profile Photo | ❌ Optional | ✅ If set |
| Location | ✅ Yes (for Goal Clubs) | ⚙️ User choice |
| Bio | ❌ Optional | ✅ If set |

## Revenue Model

### Free Tier
- Full platform access
- Virtual badges/patches
- Unlimited goals

### Revenue Streams
1. **Physical Merchandise** - Pins, badges, patches for goal completion
   - Standard platform badges
   - Limited edition event badges
   - "Founder" badges for early adopters
   - Collectible display items (sash/banner for badges)
2. **Event Organiser Fees** - Subscription or per-event fees for organisers
3. **Badge Marketplace** (future) - Commission on community/partner badge sales
4. **Premium Features** (potential future) - Advanced analytics, custom badges, etc.

## Key Features

### Social/Community
- Follow other users
- Join shared goals collaboratively
- "Cheer" button for encouragement (name TBD - see below)
- Progress sharing with photos
- Local Goal Clubs (geographic + interest based)
- Accountability Partners (future)

### Gamification
- Virtual badges/patches (auto-assigned)
- Physical badges/patches (purchasable)
- Milestone celebrations (25%, 50%, 75%, 100%)
- Streaks for recurring goals
- Leaderboards (opt-in, future)

### Activity Logging
- Manual entry (MVP)
- Photo uploads with progress updates
- Integration with fitness apps (post-launch):
  - Phase 1: Strava
  - Phase 2: Apple Health, Fitbit, Garmin

### Progress Visualisation
- Maps showing routes/locations
- Charts for habit/distance goals
- Journey photo albums
- Shareable milestone moments

### Goal Templates (future)
- Pre-built goal journeys users can adopt
- Examples: "Couch to 5K", "Complete all Wainwrights", "Visit 50 NT Sites"

### Time-Limited Challenges (future)
- Community-wide challenges with deadlines
- Adds urgency and encourages repeat participation
