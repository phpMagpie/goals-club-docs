# Goals Club - Project Status Summary

**Last Updated:** March 8, 2026

## Project Overview

The Goals Club is a service where people can set, share, and encourage others to complete goals. Goals can include organised events, fitness milestones, location-based challenges (Wainwrights, National Trust), habit tracking, and more.

## Repository Structure

Multi-repo approach:
- `goals-club-data` - Backend: Aurora Serverless, AppSync GraphQL, Cognito, Lambda
- `goals-club-admin` - Admin UI: React + Refine + Mantine
- `goals-club-web` - Public web app: React + Mantine + Mapbox
- `goals-club-shared` - Shared package published to CodeArtifact

## Database Schema

Key tables implemented:
- `users` - User profiles with cognito_id
- `goals` - Goal templates (item-based, recurring/value-based)
- `goal_items` - Individual items to complete (peaks, locations)
- `goal_types` - Lookup table for goal types
- `user_goals` - User's joined goals
- `user_goal_activities` - Activity logs (completions, progress)
- `user_goal_periods` - Streak tracking for recurring goals
- `badges` - System and goal-specific badges
- `user_badges` - Awarded badges
- `categories` - Goal categories

## Key Features Implemented

### Goals System ✅
- Item-based goals (complete X items from a list)
- Recurring/value-based goals (hit target X times/distance per period)
- Public goals that users can join
- Private/custom goals
- Goal visibility settings (PUBLIC, FRIENDS_ONLY, PRIVATE)

### Activity Logging ✅
- Log item completions
- Log additional visits to completed items
- Log progress for recurring goals
- Pipeline resolver for activity + period tracking

### Streak Tracking ✅
- `user_goal_periods` table tracks period achievements
- Current streak, longest streak, total completed periods
- Visual period history with tick/cross indicators
- Works for daily, weekly, monthly frequencies

### Maps Integration ✅
- Mapbox GL for location-based goals
- Markers for completed/incomplete items
- Popup details with completion status
- Only shows for goals with location data

### Authentication ✅
- Cognito with separate Admin and Web app clients
- Admin users in "Admins" group
- Self-registration for web users
- Auto-create user record on first login

## AppSync Resolvers Structure

**📖 Runtime Guidelines:** [`APPSYNC_JS_RUNTIME.md`](./APPSYNC_JS_RUNTIME.md)

Resolvers are organized by model in:
`packages/infra/modules/appsync-rds/resolvers/src/`

`packages/infra/modules/appsync-rds/pipeline-functions/src/`

- `getGoalPeriodInfo.js`

## Build Commands

```bash
# Data repo
cd goals-club-data
make deploy          # Full deploy (builds resolvers, deploys, runs migrations/seeds)
make preview         # Preview only
make destroy         # Tear down stack

# Web/Admin repos
cd goals-club-web    # or goals-club-admin
make deploy          # Build and deploy

# Shared package
cd goals-club-shared
bun run publish:patch && bun run publish:sdk
```
