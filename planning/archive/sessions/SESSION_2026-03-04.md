## 📋 Database Schema Notes

The `goals` table design already supports "template" goals through:
- `visibility: 'public'` - makes goal discoverable
- `allow_joins: true` - allows users to join
- `total_items` - cached count for performance

No `is_template` column needed - the combination of these fields makes a goal joinable.

## 🐛 Issues Fixed

1. **Enum Case Mismatch**: Schema stores `'public'`, `'active'` (lowercase) but seeder was using `'PUBLIC'`, `'ACTIVE'` (uppercase)
   - Fixed seeder to match schema

2. **Missing Column**: Seeder referenced `is_template` column that doesn't exist
   - Removed from seeder, used existing `allow_joins` and `visibility` fields instead

## 💡 Lessons Learned

1. **OSM Data Quality**: OpenStreetMap provides good coverage but requires filtering
   - Many subsidiary facilities (car parks, cafés) need to be excluded
   - Type field inconsistent, need keyword-based filtering too

2. **Schema Alignment**: Always check existing schema before adding fields
   - The goals table already had the right structure for templates
   - No need for additional `is_template` flag

3. **Enum Consistency**: Database stores lowercase, GraphQL expects uppercase
   - Need to standardize on one approach across the stack
   - Currently handling both via case-insensitive resolvers
