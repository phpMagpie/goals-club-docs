## 🔧 Known Issues

### Build Issue (esbuild)
Occasionally `bun run build` fails with "The service was stopped" error in `goals-club-web/packages/ui`:

**Solution:**
```bash
pkill -9 -f esbuild
pkill -9 -f vite
cd goals-club-web
rm -rf node_modules/.cache node_modules/.vite packages/ui/node_modules/.vite
cd packages/ui && bun run build
```

Or use `npx vite build` directly which seems more stable.

### Mapbox Token
The map works locally using your token in `.env.local`. 

To deploy with map enabled, ensure Pulumi config has token:
```bash
cd goals-club-web/packages/infra
pulumi config set mapboxToken pk.your_token_here --stack dev
```
